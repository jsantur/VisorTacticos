## 📌 Acerca del Proyecto

El **Visor Táctico de Seguridad Ciudadana** es una aplicación web desarrollada para facilitar la consulta y visualización de información territorial relacionada con la gestión operativa de seguridad ciudadana en la jurisdicción de **Talara**.

La plataforma permite localizar rápidamente sectores, parques, colegios, grifos y otros puntos de interés, utilizando filtros por zonas y un buscador de despliegue rápido.

Su objetivo es proporcionar una herramienta visual y práctica que facilite la identificación de sectores priorizados, puntos clave y zonas de interés durante las actividades operativas.

## 🎯 Objetivos

* Facilitar la consulta rápida de sectores de la jurisdicción.
* Organizar territorialmente las zonas de intervención.
* Visualizar puntos críticos y puntos de interés asociados.
* Mejorar el acceso a información geográfica durante los turnos operativos.
* Facilitar la planificación y despliegue del personal.
* Centralizar información territorial en una interfaz web sencilla.
* Permitir el acceso desde computadoras y dispositivos móviles.
